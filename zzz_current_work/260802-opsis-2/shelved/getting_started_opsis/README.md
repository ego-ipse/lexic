# Sessions to open

Files to load into opsis and take apart. Start it from the repo root::

    uv run python -m opsis

then use the **open** button in the bar. A `.session.ir` file THAWS —
it replaces the session with the one it records — so opening one puts
you straight into a set-up workspace.

| file | what it stresses |
|---|---|
| `ladder.session.ir` | the meta ladder: a flavour reading its own grammar, and a grammar reading a document |
| `lanes.session.ir` | one language spelled three ways — the `≅` verdict is computed, not labelled |
| `ambiguous.gbnf` | a grammar whose texts derive many ways; the floor refuses and the resolver plug is the way through |
| `deep.gbnf` | deep nesting — the chart, the forest and the tree windows at depth |
| `wide.gbnf` | many rules — the rules graph and the railroad at width |
| `tokens.session.ir` | a token grammar wanting a vocabulary it has not got: the plug window says so |

A session file names the files it holds rather than copying them, so
these stay honest if you edit the grammars beside them.
