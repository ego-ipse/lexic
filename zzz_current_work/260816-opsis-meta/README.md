## The reframes this effort exists to absorb (ruled 2026-08-16)

1. **Any lexic work is in scope.** Opsis reveals, and by revealing shows
   ways to improve lexic. The ownership presumption is reversed.
2. **The pipeline is a cycle, and the cycle has a geometry** — the ring of
   a subject's representations, the altitude axis to the metagrammar, the
   interior descent into a value, the lateral shift to attachments — and
   navigation happens IN that geometry.
3. **Universal rendering.** Opsis renders any text given the grammar that
   reads it plus the plugs the reading requires. Vyx is an instance, not
   the definition.
4. **No sacred cows.** src work has not started; the reading room's
   *behavior* is the bar, its code is a quarry like everything else.
