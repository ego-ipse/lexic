# `compile/notation` — the IR-constructor notation

One neutral, no-`exec` text surface for IR objects, in two halves plus the
flavour loader that builds on them. The round-trip fixpoint —
`load_ir(emit_ir(x)) == x` — is the gate between the halves.

## `parse.py` — the PARSE half

`load_ir(text)` parses the notation into **real IR objects** through the same
fold machinery that builds user models: one generic-apply grammar
(`value ::= name-call | str | int`, positional `SYMBOLS[name](*args)`) plus
the curated **`SYMBOLS` whitelist** — every public `IrSelf` subclass across
the `lexic.ir` modules (`base`/`bind`/`nodes`/`operators`/`action`/`mapping`/
`flavour`/`layout`), plus fixed extras (`IrNone`, `YIELD`, `True`, `False`,
…). The whitelist **is** the no-`exec` boundary and the open-vocabulary
registry: a new IR node is one entry, zero grammar change. String decode is
structural (one rule per escape kind), `INTERN` maps `Yield()` to the
canonical `YIELD`, trailing commas parse via the gateable arg-tail shape, and
a misplaced bare comma refuses at fold time. `NOTATION_FOLD` is public — the
module self-grammar embeds these rules wholesale.

## `emit.py` — the EMIT half

`emit_ir(node, width)` renders IR back to notation text through a per-tier
`IrTypeMap` over layout docs (`lexic.ir.layout`): scalars spell as
constructor calls, records omit trailing defaults, broken calls emit
black-style trailing commas and double-quoted strings (`black_quoted`) — a
fresh export is an isort + ruff-format **fixpoint**. `emit_ir` refuses
`IrLambda` (an unlocatable callable has no honest spelling).

## `loader.py` — the manifest loader

`load_flavour(text)` folds a manifest — ONE notation `IrMap` of seven strict
sections (identity, escapes-as-IR-dyads, grammar, reductions, actions) — into
a synthesized `IrFlavour`. It **derives** the reducer noise map and
`literal=DROP` from the grammar's own `semantic=False` flags (the loader owns
reducer policy; manifests carry no noise section), lowers the escape dyads to
an `EscapeCodec`, and builds the `Reducer`. A non-derivable noise policy is a
named format violation (`UnsupportedConstructError`). Shipped flavours stay
authored in `lexic.grammars`; the `*.flavour.ir` manifests are their
conformance twins, regenerated by `tools/gen_manifests.py`.
